# Universal EQ - releases

Installable APKs and update manifests for Universal EQ.

This repository contains **release artifacts only**. There is no source code here, and no credentials are embedded in any APK.

## Install

Download the newest `Universal-EQ-<version>.apk` from the releases page and open it on Android 8 or newer. The system EQ needs Android 9 or newer.

## In-app updates

The app checks this repository on launch and offers the next version. Each release is tagged `universal-eq-v<versionCode>` and carries:

- `Universal-EQ-<version>.apk`
- `universal-eq-update.json`
- `update.json`

Only the APK and these manifests are published. Source code and build outputs are never uploaded here.
